Multiplying right to left

  • Middle school: problems 1–20
  • High school: problems 1–20

Use it when: Any two-digit product with no special pattern. This is the default when nothing else fits.

How to do it

  1. Multiply the ones digits. Write the last digit and carry the rest.
  2. Cross-multiply (outer + inner), add the carry, write one digit, carry the rest.
  3. Multiply the tens digits, add the carry, and write it all.
  4. For 74×23⁠: 4⋅3=12⁠, write 2. Then 7⋅3+4⋅2+1=30⁠, write 0. Then 7⋅2+3=17⁠. Answer: 1702.

Worked example

66×32=
  1. Work right to left, one column at a time. Each column adds the cross products that land there.
  2. ones: 6×2 → write 2, carry 1
  3. tens: 6×3+6×2+1 carried =31 → write 1, carry 3
  4. hundreds: 6×3+3 carried =21 → write 1, carry 2
  5. Bring down the last carry: 2
  6. Answer: 2112
Why it works(10a+b)(10c+d)=100ac+10(ad+bc)+bd⁠. Each column of the answer is one of those three pieces.
Watch outWrite each digit as soon as you have it, right to left. Holding the whole answer in your head is where most mistakes happen.
