a1​+ab1​+ab21​

  • Middle school: problems 41–60
  • High school: problems 21–40

Use it when: Three fractions where each bottom is the previous one times the same number, like 31​+121​+481​⁠.

How to do it

  1. Use the last bottom, ab2⁠, for all three.
  2. The tops become b2+b+1 (or b2−b−1 for the minus version).
  3. 31​+121​+481​=4816+4+1​=4821​=167​⁠.

Worked example

31​+61​+121​=
  1. Each denominator is 2 times the one before, so use 12 for all three.
  2. Numerators: 4+2+1=7⁠. So 7/12, reduced: 127​
Why it worksa1​=ab2b2​ and ab1​=ab2b​⁠.
Watch outReduce at the end.
