Permutations, combinations, factorials

  • Middle school: problems 41–60
  • High school: problems 41–60

Use it when: n​Pr​⁠, n​Cr​⁠, factorial ratios and arranging letters.

How to do it

  1. n​Pr​⁠: multiply r numbers counting down from n⁠.
  2. n​Cr​=n​Pr​÷r!⁠.
  3. Letters with repeats: n! divided by the factorial of each repeat count.
  4. b!a!​⁠: multiply down from a until you reach b+1⁠.
  5. Numbers made from given digits: fill the restricted place first (no leading 0, an odd last digit, a big enough first digit), then count down for the rest.
  6. Pascal's rule: n​Ck​+n​Ck+1​=n+1​Ck+1​⁠.
  7. A committee of k from n people: (kn​)⁠. People in a line: n!⁠. Outfits: multiply the choices.

Worked example

How many 3-digit numbers greater than 100 can be made from the digits 8, 5, 1, 0 with no digit repeated?
  1. The first digit has to be 1 or more: 3 choices. With no repeats, the rest can never all be 0, so every one of those works.
  2. Answer: 18
Why it worksOrder matters in a permutation and not in a combination.
Watch outn​Cr​=n​Cn−r​⁠, so 10​C8​=10​C2​=45⁠.
