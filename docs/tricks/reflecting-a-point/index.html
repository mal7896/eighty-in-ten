Reflecting a point

  • Middle school: problems 41–60
  • High school: problems 41–60

Use it when: Reflect (x,y) across an axis, the origin, or a line like y=x+c⁠.

How to do it

  1. x−axis: (x,−y)⁠. y−axis: (−x,y)⁠. Origin: (−x,−y)⁠.
  2. y=x⁠: swap, (y,x)⁠. y=−x⁠: swap and change both signs, (−y,−x)⁠.
  3. y=x+c⁠: (y−c, x+c)⁠. y=−x+c⁠: (c−y, c−x)⁠.
  4. y=k⁠: (x, 2k−y)⁠. x=k⁠: (2k−x, y)⁠.

Worked example

The point (6, 2) is reflected across the x-axis to the point (h,k)⁠. Find k−h⁠.
  1. Change the sign of y⁠.
  2. (h,k)=(6,−2)⁠, so k−h= −8
Why it worksThe image is the same distance on the other side of the line. For y=x+c⁠: slide everything down c⁠, swap, and slide back up.
Watch outRead the question. It usually asks for h+k or h−k⁠, not the point itself.

Try these

  1. The point (−6,−2) is reflected across the line y=3 to the point (h,k)⁠. Find h+k⁠.
    Show the answer

    2

    1. x stays. y goes the same distance past 3:2(3)−(−2)=8⁠.
    2. (h,k)=(−6,8)⁠, so h+k= 2
  2. The point (3,−8) is reflected across the origin to the point (h,k)⁠. Find k−h⁠.
    Show the answer

    11

    1. Change both signs.
    2. (h,k)=(−3,8)⁠, so k−h= 11
  3. The point (9,−3) is reflected across the x-axis to the point (h,k)⁠. Find h+k⁠.
    Show the answer

    12

    1. Change the sign of y⁠.
    2. (h,k)=(9,3)⁠, so h+k= 12
  4. The point (0,−7) is reflected across the line y=x+19 to the point (h,k)⁠. Find h−k⁠.
    Show the answer

    −45

    1. Across y=x+c⁠, the point (a,b) goes to (b−c,a+c)⁠: (−7−(19),0+(19))⁠.
    2. (h,k)=(−26,19)⁠, so h−k= −45
