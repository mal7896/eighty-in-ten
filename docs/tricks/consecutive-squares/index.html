Consecutive squares

  • Middle school: problems 21–40
  • High school: problems 21–40

Use it when: Two squares next to each other, like 352+362⁠.

How to do it

  1. Square the friendly one (ending in 0 or 5).
  2. Double it, add twice the number, add 1: 2(1225)+70+1=2521⁠.

Worked example

302+312=
  1. 312=302+2⋅30+1, so the sum is 2⋅302+2⋅30+1⁠.
  2. 2×900+60+1
  3. Answer: 1861
Why it worksn2+(n+1)2=2n2+2n+1⁠.
Watch outIf the friendly number is the larger one, use 2n2−2n+1 with n as the larger.
