Rounding square roots

  • Middle school: problems 41–60
  • High school: problems 41–60

Use it when: "Round (5​+3​) to the nearest tenth", "Round 7​ to the nearest hundredth", "Round 1002​ to the nearest whole number".

How to do it

  1. Know these to three places: 2​≈1.414⁠, 3​≈1.732⁠, 5​≈2.236⁠, 6​≈2.449⁠, 7​≈2.646⁠, 10​≈3.162⁠.
  2. Add or subtract the decimals, then round once at the end: 5​+3​≈2.236+1.732=3.968 → 4.0.
  3. For any other root, start from the square just below: n​≈s+2sn−s2​⁠. 40​≈6+124​=6.33 (it's 6.325). This guess always runs a little high.
  4. A multiple of a root: multiply the decimal. 1002​≈141.4 → 141.

Worked example

Round 58​ to the nearest tenth.
  1. 72=49, so 58​≈7+9/14≈7.643⁠, a touch high; it's 7.6158.
  2. To the nearest tenth: 7.6
Why it works(s+d)2=s2+2sd+d2⁠. When d is small, d2 hardly matters, so d≈2sn−s2​⁠.
Watch outRound only once. Rounding each root first can push the total over the line: 2​+7​≈4.06⁠, but 1.4+2.6=4.0⁠.

Try these

  1. Round 3​ to the nearest hundredth.
    Show the answer

    1.73

    1. 3​≈1.732⁠.
    2. To the nearest hundredth: 1.73
  2. Round (15​−6​) to the nearest tenth.
    Show the answer

    1.4

    1. 32=9, so 15​≈3+6/6≈4.000⁠, a touch high; it's 3.8730; 6​≈2.449⁠.
    2. Difference ≈1.423⁠.
    3. To the nearest tenth: 1.4
  3. Round 52​ to the nearest tenth.
    Show the answer

    7.2

    1. 72=49, so 52​≈7+3/14≈7.214⁠, a touch high; it's 7.2111.
    2. To the nearest tenth: 7.2
  4. Round 103​ to the nearest tenth.
    Show the answer

    17.3

    1. 3​≈1.732⁠, so 103​≈10×1.732=17.32⁠.
    2. To the nearest tenth: 17.3
