Inequalities

  • Middle school: problems 41–60
  • High school: problems 41–60

Use it when: The largest integer solution, or counting integers that satisfy ∣x−h∣<k⁠.

How to do it

  1. Solve like an equation. Flip the sign if you multiply or divide by a negative.
  2. ∣x−h∣<k means h−k<x<h+k⁠: that's 2k−1 integers. With ≤ it's 2k+1⁠.
  3. x(x−k)<N⁠: start near N​ and test the integers on each side.

Worked example

The largest integer x such that 4x+8<24 is
  1. 4x<16, so x<4⁠.
  2. Largest integer: 3
Why it works∣x−h∣ is the distance from x to h⁠.
Watch outA strict < leaves out the endpoint.

Try these

  1. The largest integer x such that x(x+2)<78 is
    Show the answer

    7

    1. x(x+2) is about x2⁠, so start near 78​≈8.8⁠.
    2. 7: 63 is under 78; 8: 80 is too big. Answer 7
  2. How many integers satisfy ∣x−1∣≤3⁠?
    Show the answer

    7

    1. −2≤x≤4⁠.
    2. Count: 7
  3. How many integers satisfy ∣x+2∣≤5⁠?
    Show the answer

    11

    1. −7≤x≤3⁠.
    2. Count: 11
  4. The largest integer x such that 3x+9<22 is
    Show the answer

    4

    1. 3x<13, so x<431​⁠.
    2. Largest integer: 4
