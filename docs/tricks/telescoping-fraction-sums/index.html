Telescoping fraction sums

  • Middle school: problems 41–60
  • High school: problems 21–40

Use it when: Sums like 61​+121​+201​+301​⁠, where each bottom is two consecutive numbers multiplied.

How to do it

  1. Factor each bottom: 2⋅3, 3⋅4, 4⋅5, 5⋅6⁠.
  2. Add the numerators and divide by (first factor × last factor): 2⋅64​=31​⁠.
  3. Reciprocals of the first n triangular numbers, 1+31​+61​+⋯⁠, add up to n+12n​⁠.

Worked example

303​+423​+563​+723​=
  1. Denominators are 5⋅6,6⋅7,7⋅8,8⋅9⁠.
  2. Sum of numerators over (first factor × last factor):12/(5×9)⁠.
  3. Answer: 154​
Why it worksn(n+1)1​=n1​−n+11​⁠, so the middle terms cancel.
Watch outIf every numerator is k⁠, the top is k times the number of terms.
