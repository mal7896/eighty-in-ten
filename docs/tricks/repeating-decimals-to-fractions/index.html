Repeating decimals to fractions

  • Middle school: problems 21–40
  • High school: problems 21–40

Use it when: A decimal whose digits repeat forever.

How to do it

  1. Everything repeats: put the repeating block over that many 9s. .27=9927​=113​⁠.
  2. Some digits don't repeat: (all the digits − the part that doesn't repeat) over 9s then 0s. .23=9023−2​=307​⁠.
  3. Reduce.
  4. To add repeating decimals, turn each into a fraction first: .4+.2+.6=912​=131​⁠.

Worked example

.333…=
  1. One digit repeating: put it over 9.
  2. 3/9= 31​
Why it worksMultiplying by 10 or 100 and subtracting cancels the endless tail.
Watch outOne 9 for each repeating digit, one 0 for each digit that doesn't repeat.

Try these

  1. .125+.5−.625=
    Show the answer

    0

    1. These are 8ths: 1/8,4/8,5/8⁠.
    2. 1+4−5=0, over 8: 0
  2. The additive inverse of 1.222… is
    Show the answer

    −192​ or −911​

    1. 1.222…=911​⁠.
    2. Change the sign: −911​
  3. .3555…=
    Show the answer

    4516​

    1. One digit, then one repeating: (all digits − the part that doesn't repeat) over 90.
    2. (35−3)/90=32/90 → 4516​
  4. .3125−.6875+.9375=
    Show the answer

    169​

    1. These are 16ths: 5/16,11/16,15/16⁠.
    2. 5−11+15=9, over 16: 169​
