Times 101 and 1001

  • Middle school: problems 1–20
  • High school: problems 1–20

Use it when: One factor is 101, 1001 or 10101.

How to do it

  1. Two digits times 101: write the number twice. 47×101=4747⁠.
  2. Three digits times 1001: write it twice. 352×1001=352352⁠.
  3. Anything else times 101: n×100+n⁠.

Worked example

73×101=
  1. A two-digit number times 101 just repeats: 7373.
  2. Answer: 7373
Why it works101=100+1⁠, so you're adding the number to a shifted copy of itself.
Watch outThree digits times 101 overlap: 438×101=43800+438=44238⁠.

Try these

  1. 101×40=
    Show the answer

    4040

    1. A two-digit number times 101 just repeats: 4040.
    2. Answer: 4040
  2. 101×5770=
    Show the answer

    582,770

    1. 101=100+1, so this is 5770×100 plus 5770.
    2. 577,000+5770= 582,770
  3. 101×99=
    Show the answer

    9999

    1. A two-digit number times 101 just repeats: 9999.
    2. Answer: 9999
  4. 10,101×69=
    Show the answer

    696,969

    1. A two-digit number times 10101 repeats three times.
    2. Answer: 696,969
