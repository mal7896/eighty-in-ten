Trig values and identities

  • High school: problems 61–80

Use it when: Special angles, sin2+cos2⁠, radians, periods and inverse trig.

How to do it

  1. Know sine and cosine at 0°, 30°, 45°, 60°, 90°, and use reference angles.
  2. sin2θ+cos2θ=1 for any angle.
  3. Degrees to radians: multiply by 180π​⁠. The period of sinbx is b2π​⁠.
  4. Inverse trig: Arcsin and Arctan give angles from −2π​ to 2π​⁠, Arccos from 0 to π⁠. So Arccos(−21​)=32π​⁠.
  5. sec(sin−1.6)⁠: draw the 3−4−5 triangle. A sine of .6 means opposite 3 and hypotenuse 5, so the secant is 45​⁠.
