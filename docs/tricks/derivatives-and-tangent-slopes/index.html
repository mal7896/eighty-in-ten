Derivatives and tangent slopes

  • High school: problems 61–80

Use it when: f′(a)⁠, f′′(a)⁠, or the slope of a tangent line.

How to do it

  1. Power rule: dxd​xn=nxn−1⁠.
  2. Differentiate, then plug in.
  3. The tangent slope at x=a is f′(a)⁠.
  4. Given f′(x) and one value of f⁠: undo the derivative, then use the value for the constant. f′(x)=6x⁠, f(−1)=3 → f=3x2+C⁠, C=0⁠, so f(−3)=27⁠.
  5. Trig: (sinx)′=cosx⁠, (cosx)′=−sinx⁠. Two derivatives of cosx is −cosx⁠, so f′′(60∘)=−21​ for f=cosx⁠.
  6. Chain rule: dxd​(ax+b)n=n(ax+b)n−1⋅a⁠. Plug in for the inside first, then multiply.

Worked example

If f(x)=4x2−3x+8⁠, then f′′(−2)=
  1. f′(x)=8x−3⁠; f′′(x)=8⁠.
  2. f′′(−2)= 8
Why it worksThe derivative is the slope.
Watch outConstants disappear.
