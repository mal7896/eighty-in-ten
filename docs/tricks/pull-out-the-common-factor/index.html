Pull out the common factor

  • Middle school: problems 1–20
  • High school: problems 1–20

Use it when: Two products that share a number, like 17×23+17×77⁠, or n2+n⁠.

How to do it

  1. Find the shared factor.
  2. Combine what's left. It's usually a round number: 17×(23+77)=1700⁠.
  3. n2+n=n(n+1)⁠, so 492+49=49×50=2450⁠.

Worked example

22×76−22×66=
  1. Pull out the 22:22×(76−66)=22×10⁠.
  2. Answer: 220
Why it worksab+ac=a(b+c)⁠.
Watch outSometimes the factor is hiding: in 48×11+44×12⁠, the 44 is 4×11⁠.
