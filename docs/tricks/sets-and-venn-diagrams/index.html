Sets and Venn diagrams

  • Middle school: problems 41–60
  • High school: problems 21–40

Use it when: Number of subsets, unions, "how many play neither".

How to do it

  1. A set with n elements has 2n subsets, and 2n−1 proper subsets.
  2. ∣A∪B∣=∣A∣+∣B∣−∣A∩B∣⁠.
  3. Subsets with exactly k elements: (kn​)⁠. Exactly half of all subsets have an even number of elements: 2n−1⁠.
  4. Working back: a set with 256 subsets has 8 elements, because 28=256⁠.

Worked example

How many subsets does {M, A, T, H, S, U} have?
  1. A set with 6 elements has 26=64 subsets.
  2. Answer: 64
Why it worksEach element is either in a subset or not.
Watch outThe empty set counts as a subset.

Try these

  1. A set with 64 subsets has how many elements?
    Show the answer

    6

    1. A set with n elements has 2n subsets.
    2. 64=26⁠, so n= 6
  2. Set A has 7 elements, set B has 7, and A ∩ B has 4. How many elements are in A ∪ B?
    Show the answer

    10

    1. ∣A ∪ B∣=∣A∣+∣B∣−∣A ∩ B∣⁠.
    2. 7+7−4= 10
  3. How many proper subsets does {M, A, T, H, S, U, P} have?
    Show the answer

    127

    1. A set with 7 elements has 27=128 subsets; proper subsets leave out the set itself.
    2. Answer: 127
  4. Set A has 7 elements, set B has 6, and A ∩ B has 3. How many elements are in A ∪ B?
    Show the answer

    10

    1. ∣A ∪ B∣=∣A∣+∣B∣−∣A ∩ B∣⁠.
    2. 7+6−3= 10
