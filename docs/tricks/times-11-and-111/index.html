Tricks › Multiplying fast

Times 11 and 111

  • Middle school: problems 1–20
  • High school: problems 1–20

Use it when: One factor is 11 or 111.

How to do it

  1. Write the last digit.
  2. Moving left, write the sum of each pair of neighbors. Carry if a sum is 10 or more.
  3. Finish with the first digit plus any carry: 523×11=5753⁠.
  4. For 111, add three neighbors at a time instead of two.

Worked example

11×76=
  1. Write the ones digit, then add each pair of neighbors, moving left.
  2. ones: 6 → write 6
  3. tens: 6+7=13 → write 3, carry 1
  4. hundreds: 7+1 carried =8 → write 8
  5. Answer: 836
Why it works11=10+1⁠, so each digit of the answer is a digit plus its neighbor.
Watch outCarries are easy to forget: 87×11=957⁠, not 8157.

    2. ones: 0 → write 0
    3. tens: 0+5=5 → write 5

  2. 953×11=
    Show the answer

    10,483

    1. Write the ones digit, then add each pair of neighbors, moving left.
    2. ones: 3 → write 3
    3. tens: 3+5=8 → write 8
    4. hundreds: 5+9=14 → write 4, carry 1
    5. thousands: 9+1 carried =10 → write 0, carry 1
    6. Bring down the last carry: 1
    7. Answer: 10,483
  3. 47×11=
    Show the answer

    517

    1. Write the ones digit, then add each pair of neighbors, moving left.
    2. ones: 7 → write 7
    3. tens: 7+4=11 → write 1, carry 1
    4. hundreds: 4+1 carried =5 → write 5
    5. Answer: 517
  4. 111×543=
    Show the answer

    60,273

    1. Same idea as ×11, but add digits three at a time.
    2. ones: 3 → write 3
    3. tens: 3+4=7 → write 7
    4. hundreds: 3+4+5=12 → write 2, carry 1
    5. thousands: 4+5+1 carried =10 → write 0, carry 1
    6. ten-thousands: 5+1 carried =6 → write 6
    7. Answer: 60,273
