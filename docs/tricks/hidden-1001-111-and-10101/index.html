Hidden 1001, 111 and 10101

  • Middle school: problems 21–40
  • High school: problems 21–40

Use it when: You see 143, 77, 91, 37, 259, 429, 1443 or 3367 next to a number that shares a factor with it.

How to do it

  1. Know these: 7⋅11⋅13=1001⁠, 3⋅37=111⁠, 3⋅259=777⁠, 7⋅429=3003⁠, 3⋅3367=7⋅1443=10101⁠.
  2. Pull the missing factor out of the other number.
  3. 143×56=143×7×8=1001×8=8008⁠.
  4. Backwards: if (3)(7)(13)(k)=40404⁠, see 40404=4×10101 and 10101=3⋅7⋅13⋅37⁠, so k=4⋅37=148⁠. Also 1001=7⋅11⋅13⁠, 111=3⋅37⁠, 1111=11⋅101⁠.

Worked example

39×77=
  1. Spot it: 77×13=1001⁠.
  2. 39=13×3, so 77×39=1001×3⁠.
  3. Answer: 3003
Why it worksTest writers pick the second number on purpose so the product lands on a repeating number.
Watch outMatch the partner: 143 needs 7, 77 needs 13, 91 needs 11, 37 and 259 need 3, 429 and 1443 need 7, 3367 needs 3.
