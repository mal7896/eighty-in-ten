Same front, backs add to 10

  • Middle school: problems 1–20
  • High school: problems 1–20

Use it when: Like 43×47 (same tens digit, ones add to 10), or the flip, 34×74 (same ones digit, tens add to 10).

How to do it

  1. Same front: front ×(front +1)⁠, then the backs multiplied as two digits. 43×47 → 4×5=20⁠, 3×7=21 → 2021.
  2. The flip: fronts multiplied plus the shared back, then the back squared as two digits. 34×74 → 3×7+4=25⁠, 42=16 → 2516.
  3. Three digits work the same way when the first two digits match: 342×348 → 34×35=1190⁠, 2×8=16 → 119016.

Worked example

28×22=
  1. Fronts match (2) and the backs add to 10 (8+2)⁠.
  2. Front × next number: 2×3=6⁠.
  3. Backs multiplied, always two digits: 8×2=16⁠.
  4. Answer: 616
