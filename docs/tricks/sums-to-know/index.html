Sums to know

  • Middle school: problems 21–40
  • High school: problems 1–20

Use it when: 1+2+⋯+n⁠, and sums of odds, evens, squares and cubes.

How to do it

  1. 1+2+⋯+n=2n(n+1)​⁠.
  2. First n odds: n2⁠. First n evens: n(n+1)⁠.
  3. Squares: 6n(n+1)(2n+1)​⁠. Cubes: (2n(n+1)​)2⁠.
  4. Any arithmetic series: number of terms × average of first and last.
  5. An odd number of evenly spaced terms: count × middle term. 27+38+49+60+71=5×49=245⁠.
  6. Triangular numbers: 1+3+6+⋯+Tn​=6n(n+1)(n+2)​⁠.
  7. 13+23+⋯+n3​=1+2+⋯+n⁠.

Worked example

1+3+5+⋯+31=
  1. There are (31+1)/2=16 odd numbers. The sum of the first k odds is k2⁠.
  2. 162= 256
Why it worksPair the first term with the last, the second with the second-to-last, and so on.
Watch outCount terms carefully: steplast−first​+1⁠.
