Asymptotes

  • High school: problems 61–80

Use it when: Horizontal and vertical asymptotes of a rational function.

How to do it

  1. Cancel common factors first. Each real zero of the remaining denominator gives a vertical asymptote.
  2. Horizontal, equal degrees: the ratio of leading coefficients.

Worked example

The vertical asymptote of y=x+1x−7​ is x=
  1. Set the bottom to 0:x=−1⁠.
  2. x= −1
Why it worksThe function blows up where you'd divide by zero.
Watch outAn excluded input gives a hole if the simplified denominator is nonzero there.
