Number bases

  • Middle school: problems 21–40
  • High school: problems 21–40

Use it when: Converting to or from bases 2–9, or adding in another base.

How to do it

  1. To base 10: multiply each digit by its place value (1,b,b2,…⁠) and add.
  2. From base 10: divide by b repeatedly and read the remainders from bottom to top.
  3. Base 2 to 4, 8 or 16: group the binary digits in 2s, 3s or 4s from the right.
  4. bn−k in base b⁠: bn is 1 followed by n zeros, so subtracting turns the zeros into (b−1)s. 64−1=55556​⁠.
  5. A fraction over b2 as a base-b decimal: write the numerator in base b⁠. 3619​=.316​ because 19=3⋅6+1⁠.

Worked example

1610​= base 3
  1. Divide by 3 repeatedly and read the remainders bottom to top.
  2. 16÷3=5r1⁠; 5÷3=1r2⁠; 1÷3=0r1
  3. Answer: 121 in base 3
Why it worksPlace value works the same way in every base.
Watch outNo digit can be as big as the base. In base 6 the digits are 0 to 5.

Try these

  1. 425​+245​= base 5
    Show the answer

    121

    1. Easiest: convert to base 10. 425​=22 and 245​=14⁠.
    2. 22+14=36, back to base 5: 121
  2. Change 496​ to a base 7 decimal.
    Show the answer

    .06

    1. Write it over 72=49⁠: 496​=496​⁠.
    2. 6=0×7+6, so the digits after the point are 0, 6: .06
  3. 21110​= base 7
    Show the answer

    421

    1. Divide by 7 repeatedly and read the remainders bottom to top.
    2. 211÷7=30r1⁠; 30÷7=4r2⁠; 4÷7=0r4
    3. Answer: 421 in base 7
  4. Change 6441​ to a base 8 decimal.
    Show the answer

    .51

    1. Write it over 82=64⁠: 6441​=6441​⁠.
    2. 41=5×8+1, so the digits after the point are 5, 1: .51
