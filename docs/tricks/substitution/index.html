Substitution

  • Middle school: problems 21–40
  • High school: problems 21–40

Use it when: "If x=4⁠, then 3x2−5x+2= ___".

How to do it

  1. Square first, then multiply, then add.
  2. Keep negatives in parentheses: (−3)2=9⁠.
  3. f(m)−f(n) for f(x)=ax+b is a(m−n)⁠: the b cancels. For ax2+b it's a(m−n)(m+n)⁠.
  4. f(x2+c)=ax+b⁠, find f(t)⁠: x=±t−c​⁠, and the two values add to 2b⁠.

Worked example

If x=1, then x2−6x−2=
  1. 1(1)2−6(1)−2
  2. =1−6−2= −7
Why it worksOrder of operations still rules.
Watch out−x2 with x=−3 is −9⁠.

Try these

  1. If f(x)=−3x+9⁠, then f(35)−f(5)=
    Show the answer

    −90

    1. The 9 cancels: f(35)−f(5)=−3×(35−5)⁠.
    2. = −90
  2. If x=1, then 5x2−4x+3=
    Show the answer

    4

    1. 5(1)2−4(1)+3
    2. =5−4+3= 4
  3. If x=0, then 5x2−7x=
    Show the answer

    0

    1. 5(0)2−7(0)+0
    2. =0+0+0= 0
  4. If x=−1, then −5x2−8x−12=
    Show the answer

    −9

    1. −5(−1)2−8(−1)−12
    2. =−5+8−12= −9
